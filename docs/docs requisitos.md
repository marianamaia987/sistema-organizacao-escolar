Requisitos do Sistema

Requisitos Funcionais

- Cadastro de matérias

O sistema deve permitir que o estudante cadastre suas matérias escolares.

 - Cadastro de atividades

O sistema deve permitir cadastrar atividades e tarefas escolares.

 - Cadastro de trabalhos

O sistema deve permitir registrar trabalhos e suas datas de entrega.

 - Cadastro de provas

O sistema deve permitir registrar provas e suas respectivas datas.

 - Cadastro de horários

O sistema deve permitir cadastrar os horários das aulas.

 - Visualização das atividades

O sistema deve apresentar as atividades cadastradas e seus respectivos prazos.

Requisitos Não Funcionais

 - Facilidade de uso

O sistema deve possuir uma interface simples e fácil de utilizar.

 - Organização

As informações devem ser apresentadas de forma organizada.

- Desempenho

O sistema deve apresentar as informações cadastradas de maneira rápida.

- Compatibilidade

O sistema deve funcionar em computadores e dispositivos móveis.
