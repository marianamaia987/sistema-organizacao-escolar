# sistema-organizacao-escolar
Sistema para ajudar estudantes a organizar atividades, provas e horários escolares.
Sistema de Organização Escolar

Problema

Muitos estudantes têm dificuldade para organizar suas atividades, trabalhos, provas e horários. Com isso, podem acabar esquecendo tarefas ou perdendo prazos importantes.

Solução

O Sistema de Organização Escolar será desenvolvido para ajudar estudantes a organizar suas atividades escolares em um único lugar. O sistema permitirá cadastrar matérias, atividades, trabalhos, provas e horários das aulas.

Objetivo

Facilitar a organização da rotina escolar dos estudantes e ajudar no acompanhamento das atividades e dos prazos de entrega.

Funcionalidades

- Cadastro de matérias;
- Cadastro de atividades;
- Cadastro de trabalhos;
- Cadastro de provas;
- Cadastro das datas de entrega;
- Cadastro dos horários das aulas;
- Visualização das atividades cadastradas.

Público-alvo

Estudantes que precisam organizar melhor suas atividades e compromissos escolares.
